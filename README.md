# MIRA: Medical Image Reflection for Agentic Diagnosis

Official project page for MIRA, a medical visual diagnostic framework for autonomous evidence search and reflective verification.

Project page: https://MIRA-VL.github.io/

## Local preview

The site is dependency-free static HTML and CSS. From the repository root, run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in a browser.

## Figures

Figures on the page are derived from the MIRA manuscript and its qualitative and quantitative analyses. The source manuscript is available at `static/pdfs/MIRA.pdf`.
